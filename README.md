## 🚀 Cara Pakai Tercepat (1-Klik)

1. Download file [`Install-Semua.bat`](Install-Semua.bat) (klik kanan → Save / atau clone repo ini)
2. Klik kanan → **Run as Administrator**
3. Pilih menu kategori (AI, Developer, Produktivitas, dll) atau install semua paket inti
4. Script akan install otomatis lewat **winget** (bawaan Windows) dari sumber resmi Microsoft

Atau jalankan manual di PowerShell:
```powershell
winget install Microsoft.PowerToys voidtools.Everything 7zip.7zip ShareX.ShareX
```

## ⚠️ Catatan Jujur

- Selalu download dari link resmi di tiap folder — jangan dari situs "full version / crack".
- Tools AI lokal butuh RAM/VRAM sesuai ukuran model; model 7-8B nyaman di RAM 16GB.
- Installer di repo ini hanya memanggil `winget install` resmi — tidak mengubah registry aneh-aneh, tidak mematikan Defender/Windows Update.
- Versi & fitur berubah cepat — link resmi selalu mengarah ke versi terbaru saat kamu download.
