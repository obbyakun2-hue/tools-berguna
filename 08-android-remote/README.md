# 📱 08 — Android & Remote HP

| Tool | Link Resmi | Kegunaan |
|---|---|---|
| **scrcpy** | https://github.com/Genymobile/scrcpy | Mirror + kontrol HP Android dari PC (USB/WiFi), resmi Genymobile |
| **ADB Platform Tools** | https://developer.android.com/tools/releases/platform-tools | adb & fastboot resmi Google |
| **LocalSend** | https://localsend.org | Transfer file Android↔PC |
| **KDE Connect** | https://kdeconnect.kde.org | Notif HP di PC, clipboard bersama, kontrol media |

Syarat scrcpy/ADB: aktifkan **USB Debugging** di HP (Pengaturan → Tentang → tap Build Number 7x → Opsi Pengembang).
