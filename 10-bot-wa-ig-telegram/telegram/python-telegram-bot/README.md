# Bot Telegram — Python

1. Chat `@BotFather` di Telegram → `/newbot` → copy token
2. `pip install -r requirements.txt`
3. Copy `.env.example` jadi `.env`, isi `BOT_TOKEN`
4. `python bot.py` lalu chat bot kamu: /start

Mau online 24 jam? Deploy file ini di VPS / Railway / Render dengan env `BOT_TOKEN` yang sama.
