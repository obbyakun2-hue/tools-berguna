# 🤖 01 — AI Lokal & AI Terbaru

AI yang jalan **di PC kamu sendiri** — privat, offline, tanpa langganan.

| Tool | Link Resmi | Catatan |
|---|---|---|
| **Ollama** | https://ollama.com | Paling mudah mulai AI lokal. `ollama run llama3.1` / `qwen3` / `deepseek-r1`. API lokal untuk developer. |
| **LM Studio** | https://lmstudio.ai | GUI ramah pemula, download model 1-klik, cocok kalau tidak mau terminal. |
| **Open WebUI** | https://github.com/open-webui/open-webui | Tampilan seperti ChatGPT untuk Ollama, bisa self-host. |
| **AnythingLLM** | https://anythingllm.com | Chat dengan PDF/dokumen kamu sendiri (RAG), multi-workspace. |
| **ComfyUI** | https://github.com/comfyanonymous/ComfyUI | Generate gambar AI (Stable Diffusion / FLUX) sistem node, paling fleksibel saat ini. |
| **Whisper** | https://github.com/openai/whisper | Transkrip suara→teks akurat banyak bahasa, termasuk Indonesia. |
| **Dify** | https://dify.ai | Buat aplikasi / agen AI visual, bisa self-host (Apache-2.0). |
| **OpenCode** | https://opencode.ai | AI coding agent terminal/desktop — lihat juga folder 02. |

**Mulai dari mana?** Pemula: LM Studio. Developer: Ollama + Open WebUI. Kreator gambar: ComfyUI.
**Spek jujur:** model 7–8B (Q4) nyaman di RAM 16GB / GPU 8GB. Model besar 32B+ butuh VRAM 24GB+.
