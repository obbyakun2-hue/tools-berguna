# 🛠️ 04 — Utilitas Sistem Windows

| Tool | Link Resmi | Kegunaan |
|---|---|---|
| **Everything** | https://www.voidtools.com | Cari file apa pun instan |
| **WizTree** | https://diskanalyzer.com | Visualisasi isi disk — ketahuan folder rakus |
| **7-Zip** | https://www.7-zip.org | ZIP/RAR/7z/ISO |
| **Revo Uninstaller** | https://www.revouninstaller.com | Uninstall + bersihkan sisa folder/registry |
| **PowerToys** | https://learn.microsoft.com/windows/powertoys/ | Lihat folder 03 |
| **WizFile / TreeSize Free** | https://diskanalyzer.com / https://www.jam-software.com/treesize_free | Alternatif analisis disk |

⚠️ Hindari "PC cleaner / driver booster" tak dikenal — mayoritas cuma iklan & bloat. Windows Defender + tools di atas sudah cukup.
